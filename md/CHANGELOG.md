### 🎉 v1.0.3 - HA 2026.11 规范适配与体验统一！

对齐 HA 2026.11 开发规范的系统性清理，修复一处随服务调用即触发的弃用 API 隐患。

### 🚀 核心提升：

#### 弃用 API 清理：
- 服务定位设备改用 `device.config_entry_id`，替代已弃用的 `device.config_entries` 兼容 shim（HA 2027.10 移除）。

#### 配置流强化：
- 「重新配置」补齐 unique_id 处理：更换接入地址时自动防与其他条目冲突，并同步刷新条目 unique_id。
- 条目标题由 `KittY (主机名)` 改为 `主机名:端口`，直观体现接入点。

#### 集成身份修正：
- 集成类型由 `hub`（中枢）改为 `device`（设备），与实体挂载方式一致。
- 协调器显式传入 `config_entry`，删除与基类重复的冗余覆写。

### 🎉 v1.0.0 - 首个公开发布！

KittY Controller：在 Home Assistant 中对 Mihomo（Clash.Meta）内核的设备化管控。

#### 核心功能：
- 实时传感器：流量、内存占用、活动连接数、内核版本与 GitHub 更新检查。
- 代理组 Select 实体：按关键词自动发现策略组，支持切换节点与固定代理。
- 服务集：核心重启、连接筛选与关闭、组/节点延迟测速、DNS 查询、规则检索、订阅与代理集合更新、集合健康检查。
- 一键重启按钮与完整诊断信息下载。
